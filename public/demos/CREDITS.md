# Exercise demo photos

Start and end photos for each exercise come from **Free Exercise DB** by yuhonas:
https://github.com/yuhonas/free-exercise-db

The dataset is released into the public domain under the Unlicense (http://unlicense.org/).
Photos were resized to 480 px wide by `scripts/fetch-demos.py`.

The welcome screen photo (`public/hero.jpg`) is a black-and-white crop of the Barbell Squat start photo from the same dataset.
